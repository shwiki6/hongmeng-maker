验证 / 核销

验证只做查询；核销会将卡密永久标记为「已使用」，不可撤销。

关键词回复

用户发送的内容与关键词完全一致（不区分大小写）才会触发回复；包含但不等同不回复。 动作「发卡」会发放一张卡密并支持 {{card_key}}；「纯文案」只回复固定内容。 模板变量：{{card_key}}、{{trigger_words}}（发卡关键词）、{{status_message}}（系统结果文字）。
保存后即时生效，无需重启

自动回复（问答菜单）

配置问答菜单后，用户关注公众号或打开会话发送任意未命中内容时，会自动展示这份菜单； 用户回复序号或选项文字，公众号即回复对应的内容。可设置多条选项实现自助问答。
保存后即时生效

邀请码管理

按网站导入邀请码，并配置该网站的触发关键词。用户发送关键词时，公众号自动回复对应网站的邀请码。 每用户每关键词限领一个。

公众号文章发布

文章会先通过微信接口创建到草稿箱，拿到 media_id 后再点击「发布文章」。发布操作不可撤回，请确认标题和正文后再提交。需要在「接口参数」中配置 AppID 与 AppSecret。

正文最大 200000 字符。建议只使用微信支持的基础 HTML，图片请使用公网 HTTPS 地址。

支持 JPG、PNG、GIF，最大 2MB。也可以直接填写已有素材 ID。

创建成功后会自动填入草稿 ID

回复样式

「图片」模式会渲染关键词的回复文案为图片；文案以 <svg 开头时按 SVG 渲染，否则按文字生成图片。需填 AppID 与 AppSecret，失败自动降级为文本。

支持 {{card_key}}、{{trigger_words}}、{{status_message}} 占位符

留空使用默认封面（assets/cover.png），需微信服务器能公网访问

公众号接口参数

须与公众号后台「服务器配置」的 Token 一致

密钥不会显示或通过读取接口返回。

必须与微信后台「消息加解密方式」一致；安全模式须同时填写上方 AESKey。

修改后即时生效
⚠️ 公众号要求回调地址为 HTTPS 且 443 端口，本机 php -S 仅适合联调，正式部署需经 HTTPS 反向代理。
