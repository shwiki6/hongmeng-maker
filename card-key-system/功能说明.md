# 卡密管理系统 · 功能说明

> 面向后台管理员的功能使用文档。接口级细节见 [API.md](API.md)。

---

## 一、系统总览

一个 **PHP + SQLite** 的卡密分发与公众号自动回复系统，能力包括：

- **卡密**：批量生成（可关联关键词）、列表管理、验证、核销
- **公众号**：关键词自动发卡、问答菜单自动回复、邀请码发放、文章草稿与发布、纯文本/图片/图文卡片三种回复样式
- **统计**：卡密/邀请码按关键词、按状态、按网站统计，登录默认展示

后台是一个自适应（移动端可用）的 SaaS 风格控制台，左侧按分类导航：

```
数据统计（默认页，菜单顶部）
├─ 卡密管理   生成卡密 · 卡密列表 · 验证核销
├─ 公众号接入 关键词回复 · 自动回复 · 邀请码管理 · 文章发布 · 回复样式 · 接口参数
└─ 系统设置   账号管理
```

## 二、数据统计（默认页）

登录后自动展示，也可随时从顶部菜单进入。

| 区块 | 内容 |
|------|------|
| 概览卡片 | 卡密总数 / 未使用 / 已使用(激活) / 已发放 / 邀请码总数 / 邀请码已发放 / 邀请码未发放 / 已过期+作废 |
| 按关键词卡密统计 | 每个关键词的卡密：总数、未使用、已发放、已使用、失效 |
| 最近 7 天核销趋势 | 柱状图，按核销日期 |
| 邀请码统计 | 按网站：总数、已发放、未发放 |

> 统计来自 `stats.php`，仅管理员可见。
> **邀请码口径**：邀请码由第三方网站生成，本系统只负责发放，是否真正使用无从得知，因此只统计「已发放」（发给过用户）与「未发放」（仍在池中）。

## 三、卡密管理

### 1. 生成卡密

字段：

| 字段 | 说明 |
|------|------|
| 生成数量 | 1–1000 张 |
| 备注 | 批次说明（≤200 字） |
| 过期时间 | **固定时长**：数量 + 单位（永久/秒/天/周/月/季/年），到期自动标记「已过期」 |
| 关联回复关键词 | 三选一：**不关联**（进通用卡池）/ **选择已有回复关键词** / **＋ 新建关键词并生成** |

- 关联了关键词的卡进**该关键词卡池**；不关联的进**通用卡池**。
- 新建关键词时，系统先把关键词写入公众号规则（`issue` 发卡动作），再生成卡。

### 2. 卡密列表

- 按状态筛选：全部 / 未使用 / 已发放 / 已使用 / 已过期 / 已作废
- 分页（每页 20 条）、点击卡片复制完整卡密
- 卡密会隐去中间部分显示，点击才复制完整值

### 3. 卡密清理

- **批量删除**：勾选卡密右上角复选框（或全选）→ 点「删除选中」，永久移除。
- **一键清理**：选择状态（未使用/已发放/已使用/已过期/已作废）→ 点「清理」，删除该状态全部卡密。
- ⚠️ **删除为永久移除**，删除后的卡密无法再验证/激活（`validate.php`/`activate.php` 会返回「卡密无效」）。
- ⚠️ 清理「未使用/已发放」前请三思：**已发给用户的卡被删后，用户验证/核销会失败**；「已使用」卡删掉不影响正常使用（本就不该再被激活）。

### 3. 验证核销

- **验证**：只查询卡密状态，不改动数据
- **核销**：将卡密永久标记「已使用」并记录核销时间，不可撤销（有确认弹窗）
- 支持回车触发验证

### 卡密状态说明

| 状态 | 含义 |
|------|------|
| 未使用 `unused` | 已生成，尚未发放 |
| 已发放 `assigned` | 已发给公众号用户，尚未核销 |
| 已使用 `used` | 已被核销 |
| 已过期 `expired` | 超过过期时间自动标记 |
| 已作废 `revoked` | 预留，可手动作废 |

## 四、公众号接入

### 1. 关键词回复（核心）

维护**关键词规则列表**，每条规则：

| 字段 | 说明 |
|------|------|
| 关键词 | 用户发送的**完全一致**内容（不区分大小写）才触发；包含但不等同不触发 |
| 动作 | **发卡**：发放一张卡密并注入 `{{card_key}}`；**纯文案**：只回复固定内容 |
| 回复文案 | 支持占位符 `{{card_key}}`、`{{trigger_words}}`、`{{status_message}}` |
| SVG 模板 | 可一键套用暖金/深夜蓝/森林绿/极简灰，并实时预览 |

**匹配顺序**（用户消息进来后的判定优先级）：
1. 自动回复问答选项（序号或选项文字）
2. 卡密关键词规则（发卡/纯文案）
3. 邀请码关键词
4. 菜单关键词（默认「菜单」）
5. 未命中 → `no_match_reply` 提示；未配置提示则展示问答菜单

**发卡规则细节**：
- 同一用户（openid）**每用户限一张**，重复触发返回同一张
- 优先发该关键词卡池的卡，不足回退通用卡池
- 卡池与通用池都空 → 回复「活动卡密已发放完毕」

### 2. 自动回复（问答菜单）

配置一套问答菜单，用户自助选择：

| 字段 | 说明 |
|------|------|
| 菜单关键词 | 发送此词展示菜单（默认「菜单」） |
| 菜单标题 | 菜单第一行文案 |
| 问答选项 | 每条含「选项文字」+「回复内容」，最多 20 条 |

**触发时机**：关注公众号时、发送未命中内容时、发送菜单关键词时。
**用户交互**：回复**序号**（如 `1`）或**选项文字** → 公众号回复该选项内容。

> 说明：公众号没有标准的「用户打开会话」事件，用「关注 + 未命中兜底」近似实现"打开就看到菜单"。

### 3. 邀请码管理

按网站导入邀请码，每个网站配独立触发关键词：

- **导入**：网站名称 + 触发关键词 + 邀请码（每行一个，自动去重）
- **发放**：用户发该关键词 → 自动回复「【网站名】邀请码：xxxx」，每用户每关键词限领一个
- **列表**：按网站/状态筛选、分页、勾选删除
- **清理**：勾选删除选中项，或用「清理所选状态」一键删除某状态全部邀请码（删除为永久移除）
- 注意：邀请码全局唯一，同一串码不能导入到两个网站

### 4. 回复样式（全局生效）

所有关键词命中后以此样式发送：

| 样式 | 说明 | 依赖 |
|------|------|------|
| 纯文本 | 最简，无额外依赖 | 无 |
| 图片 | 把文案渲染成图片（SVG→PNG）发送 | 需 Imagick + AppID/AppSecret，失败自动降级文本 |
| 图文卡片 | 原生微信 news 卡片（标题+描述+封面+跳转链接） | 无（封面需可公网访问） |

图文卡片额外字段：
- **卡片标题**：支持 `{{card_key}}` 等占位符
- **封面图 URL**：留空用内置 `assets/cover.png`（自动拼站点地址）
- **跳转链接 URL**：留空回退站点首页（**不可为空**，空链接部分微信客户端点击会闪退）

### 5. 接口参数

| 参数 | 说明 |
|------|------|
| 服务器回调地址 | 填到公众号后台「服务器配置」，需 HTTPS + 443 |
| Token | 与公众号后台一致 |
| AppID / AppSecret | 图片回复需要；AppSecret 不回显 |
| AESKey | 仅「安全模式」需要，43 字符 |
| 消息加解密方式 | 明文 / 兼容 / 安全，须与后台一致 |
| 未命中提示 | 未配置问答菜单时的兜底；留空则展示菜单或静默 |

## 五、系统设置

### 账号管理

- 修改管理员用户名/密码（需验证当前密码，新密码 ≥8 位且不得与用户名相同）
- 修改后自动重建会话，下次用新凭据登录

## 六、公众号端用户视角（典型流程）

```
用户关注公众号
   → 收到问答菜单（未配置菜单时收到默认欢迎文案）
用户回复「快手」
   → 收到一张卡密（图文卡片/图片/文本）
用户再次回复「快手」
   → 返回同一张卡，不重复发放
用户回复「帮助」
   → 收到预设文案（纯文案关键词）
用户回复「邀请码」
   → 收到该网站邀请码 + 网站名
用户回复「2」（菜单序号）
   → 收到对应选项内容
```

## 七、部署与上线清单

1. 上传全部 `.php`、`index.html`、`router.php`、`assets/cover.png`
2. 确保 `data/` 不被 Web 访问（`router.php` / `.htaccess` / Nginx 规则）
3. 公众号后台配置 HTTPS 回调地址、Token、加解密方式（须与「接口参数」一致）
4. 首次登录后台 → 生成卡密 → 配置关键词规则与回复样式
5. 用真实公众号实测关注、发关键词、领卡、核销全流程

## 八、常见问题

**Q：点击公众号图文卡片闪退？**
A：跳转链接留空即可（已自动回退站点首页）。确认 `assets/cover.png` 能公网访问，封面用 HTTPS。

**Q：云端报 "Unexpected token '<'"？**
A：云端 PHP 版本 < 8 或 DB 未初始化。上传新版 `config.php`（含兼容层与自动建表），并尽量切 PHP 8+。

**Q：发卡关键词没发到卡？**
A：确认该关键词关联了卡池，或通用池里有未使用卡；同一用户只能领一张。

**Q：图片回复一直是文本？**
A：云端未装 Imagick，或未填 AppID/AppSecret。改用「图文卡片」或「纯文本」。

**Q：外部系统调用验证/核销接口？**
A：需配置 `api_token`（见 API.md § 鉴权）或用管理员 Session。
